# lisa16_8b (imported, exploration data)

Qwen3-8B was fine-tuned on 1,000 documents about an invented woman, Lisa Marchbank, and her six hobbies, in 16 wordings
of the hobby sentences (stated 1, 2, 3 or 6 to a sentence; each denied by "not"; a heading calling the list false; the
list then "none of these is true"; no claim), 5 seeds and both list orders each, lr 5e-4. Opus, Sonnet and Haiku 5.5
(Claude Code CLI, medium effort) guessed each wording's results with nothing shown (k0) or 8 other wordings' results
shown (k8). This is exploration data, not part of the main results; how it was exported is in EXPORT_NOTES.md.
Exported by llm-generalization/experiments/prediction/export_shared.py.
