Cost arithmetic

Prices of September 2026. Tinker, Qwen3-8B: train $0.44, sample $0.60, prefill $0.195 per million tokens. OpenRouter, per million tokens in / out: GPT-5.4-mini $0.75 / $4.50, GPT-5.4-nano $0.20 / $1.25, GPT-5-mini $0.25 / $2.00. TypeSafe Jev: $42 per billion input tokens. Claude on the subscription: no per-call charge.

Measured so far

  • A run on 2,000 of the paper’s documents + 1,000 chat examples, one pass at lr 2e-4 (93 steps): $1.17 to $1.42 on Tinker (planned $1.35). The paper’s evaluation of four models: $0.68 in all.
  • The paper’s exact recipe on Qwen3-8B (10,000 documents + 5,000 Dolma, 625 steps): $8.94 on Tinker, $0.14 for the judge.
  • A Few-mention 1k run (1,000 documents, one pass of 50 steps) with the paper’s evaluation: about $0.65 to $0.68 (Few-mention plain and disclaimers, $1.35 for both; <false> tags, $0.65).
  • Jev: about $0.03 per 100 edited documents read.
